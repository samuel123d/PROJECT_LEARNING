# Project Learning | Aprensizagem e Desenvolvimento

Este repositório foi concebido como um ambiente de aprendizagem colaborativa. O objetivo principal é consolidar conhecimentos avançados de desenvolvimento web enquanto sirvo de mentor, ensinando as competências técnicas fundamentais para a formação de novos programadores.

**Link de Acesso:** [Visualizar Projeto](https://samuel123d.github.io/PROJECT_LEARNING)

---

## Resumo do Projeto

O projeto funciona como um laboratório prático onde são explorados conceitos de estruturação, estilização e lógica de programação. Através de exemplos reais e exercícios guiados, o repositório documenta a evolução técnica tanto do mentor como do aprendiz.

### Tecnologias e Ferramentas

| Categoria | Tecnologias Utilizadas |
| :--- | :--- |
| **Linguagens** | HTML5 (Estruturação), CSS3 (Estilização) |
| **Conceitos** | Semântica Web, Box Model, Responsividade |
| **Metodologia** | Mentoria Prática e Code Review |
| **Hosting** | GitHub Pages |

---

## Estrutura de Diretórios

A organização foi pensada para facilitar a compreensão didática do fluxo de um projeto web:

* **Estilo/**: Ficheiros de estilização CSS organizados por módulos.
* **src/**: Componentes e recursos de suporte ao desenvolvimento.
* **index.html**: Página principal que serve como base para os exercícios.
* **horas.html**: Módulo específico para estudo de funções ou layouts temporais.

---

## Funcionalidades Principais

O projeto destaca o valor da partilha de conhecimento na área tecnológica:

> **Mentoria Técnica Ativa**
> Criação de um ambiente controlado para o ensino de conceitos base (HTML/CSS), permitindo que o aprendiz compreenda a estrutura de um site desde o zero até ao deploy final.
